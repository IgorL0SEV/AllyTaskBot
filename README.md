# AllyTaskBot 🤖

Telegram-бот для команды: собирает идеи и задачи в одном месте, хранит их в SQLite и не даёт утонуть в переписке чата.

Каждый участник может добавить задачу (с категорией и статусом), в любой момент посмотреть список всех задач или выгрузить их в CSV для Excel/LibreOffice.

## Возможности

- ➕ **Добавление задач** через FSM-сценарий: текст → категория → статус (inline-кнопки).
- 📋 **Просмотр всех задач** одной командой — с автором, категорией, статусом и датой.
- 📄 **Экспорт в CSV** — разделитель `;`, UTF-8 с BOM: открывается в Excel/LibreOffice/Google Sheets, кириллица и колонки читаются корректно.
- 👥 **Поддержка множественных пользователей** — каждая задача помечается автором (`@username` или имя).
- 💾 **Автоматическое сохранение в SQLite** — данные не теряются при перезапуске или сбое.
- 🕒 **Время по Минску** — `created_at` хранится в UTC+3, в `/list` и CSV видно локальное время.
- 🗂 **Категории и статусы** — «новое / в работе / выполнено» и «фронт-энд / бэк-энд / база данных / общее».

## Архитектура

Проект построен на трёх частях:

| Часть | Роль в проекте |
|-------|----------------|
| **Интерфейс** | Telegram — окно диалога, кнопки, сообщения |
| **Логика** | Python + aiogram — обработка команд, FSM, БД |
| **Данные** | SQLite3 — файл `data/tasks.db` |

Поток: пользователь пишет команду в Telegram → aiogram-роутер принимает её → логика пишет/читает SQLite → ответ уходит обратно в Telegram.

## Схема базы данных

Таблица `tasks`:

| Колонка     | Тип       | Описание |
|-------------|-----------|----------|
| `id`        | INTEGER PK | Уникальный идентификатор (autoincrement) |
| `text`      | TEXT      | Текст задачи / идеи |
| `user`      | TEXT      | Автор задачи (`@username` или имя) |
| `created_at`| TIMESTAMP | Дата и время создания (часовой пояс Минска, UTC+3) |
| `status`    | TEXT      | Статус: «новое», «в работе», «выполнено» |
| `category`  | TEXT      | Категория: «фронт-энд», «бэк-энд», «база данных», «общее» |

> `created_at` записывается в Python как минское время (фиксированный offset UTC+3, без летнего времени). В `/list` и `/list_csv` отображается локальное время Минска.

## Установка и запуск

### 1. Клонировать репозиторий

```bash
git clone https://github.com/IgorL0SEV/AllyTaskBot.git
cd AllyTaskBot
```

### 2. Создать виртуальное окружение и установить зависимости

```bash
python -m venv .venv
# Windows (PowerShell):
.venv\Scripts\Activate.ps1
# Linux / macOS:
source .venv/bin/activate

pip install -r requirements.txt
```

> Требуется Python 3.8+ (рекомендуется 3.11+).

### 3. Получить токен бота

1. Откройте [@BotFather](https://t.me/BotFather) в Telegram.
2. Отправьте `/newbot`, задайте имя и username.
3. Скопируйте выданный токен вида `123456789:ABC...`.

### 4. Настроить `.env`

```bash
cp .env.example .env
```

Откройте `.env` и впишите токен:

```
BOT_TOKEN=123456789:ABCyourtokenhere
DB_PATH=data/tasks.db
```

### 5. Запустить бота

```bash
python main.py
```

В консоли появится `Бот запущен. Polling started...`. Откройте бота в Telegram и отправьте `/start`.

## Команды бота

| Команда     | Действие |
|-------------|----------|
| `/start`    | Приветствие и список команд. |
| `/add`      | Добавить задачу: ввод текста → выбор категории → выбор статуса → сохранение. |
| `/list`     | Показать все задачи (с автором, категорией, статусом, датой). |
| `/list_csv` | Выгрузить все задачи в CSV-файл и отправить документом. |

## Как изменить меню (кнопки, команды, тексты)

**Все пользовательские тексты бота собраны в одном файле — `menus.py`.**
Вверху файла — легенда: какое меню для чего предназначено. Ниже — сами тексты
как константы с номерами (`MENU_1_…`, `MENU_2_…` … `MENU_12_…`).

Чтобы поменять любой текст, подпись кнопки, команду или сообщение сценария:

1. Откройте `menus.py`.
2. В **легенде** вверху найдите номер нужного меню (например, «Меню 1 — Клавиатура категорий/проектов»).
3. Ниже найдите константу с тем же номером (`MENU_1_CATEGORIES`) и отредактируйте значение.
4. Перезапустите бота.

### Легенда меню (краткая)

| Меню  | Назначение | Константа в `menus.py` |
|-------|------------|------------------------|
| 1     | Кнопки категорий (`/add`) | `MENU_1_CATEGORIES` |
| 2     | Кнопки статусов (`/add`) | `MENU_2_STATUSES` |
| 3     | Приветствие `/start` (вступление + концовка) | `MENU_3_INTRO`, `MENU_3_OUTRO` |
| 4     | Список команд (приветствие + меню Telegram) | `MENU_4_COMMANDS` |
| 5     | `/add` шаг 1: запрос текста | `MENU_5_ADD_PROMPT` |
| 6     | `/add` шаг 2: запрос категории | `MENU_6_CATEGORY_PROMPT` |
| 7     | `/add` шаг 3: запрос статуса | `MENU_7_STATUS_PROMPT` |
| 8     | `/add` успех: задача добавлена | `MENU_8_SUCCESS` |
| 9     | `/add` ошибка: данные устарели | `MENU_9_ERROR` |
| 10    | `/list`: список пуст | `MENU_10_EMPTY` |
| 11    | `/list`: заголовок + строка задачи | `MENU_11_HEADER`, `MENU_11_ROW` |
| 12    | `/list_csv`: подпись к документу | `MENU_12_CSV_CAPTION` |

### Кнопки (Меню 1 и 2)

Хранятся в dict'ах: слева — внутренний ключ (латиницей, **не меняйте** у
существующих кнопок — на него завязан callback), справа — текст, который
видит пользователь. Для категорий (Меню 1) ключи — универсальные слоты
`project1`, `project2` …; для статусов (Меню 2) — `status1`, `status2` …
Подписи справа — названия ваших проектов/статусов (меняйте под свою команду).

```python
MENU_1_CATEGORIES = {
    "project1": "Фронт-энд",    # 1.1
    "project2": "Бэк-энд",      # 1.2
    "project3": "База данных",  # 1.3
    "project4": "Общее",        # 1.4
}
```

- **Добавить кнопку** — впишите новую строку по аналогии: `"project5": "Дизайн",` → кнопка автоматически появится в `/add`.
- **Удалить** — сотрите строку.
- **Переименовать подпись** — поменяйте текст справа (ключ оставьте).
- **Порядок строк = порядок кнопок** в Telegram.

> В БД сохраняется текст справа (например, «Фронт-энд»). Если переименовать подпись, у старых задач она останется прежней — это нормально.

### Команды (Меню 4)

```python
MENU_4_COMMANDS = [
    ("add",      "добавить новую задачу"),          # 4.1
    ("list",     "посмотреть все задачи"),         # 4.2
    ("list_csv", "выгрузить все задачи в CSV-файл"),  # 4.3
]
```

Из него **автоматически** собираются:
- текст приветствия в `/start` (список `/команда — описание`);
- меню Telegram (кнопка «Menu» слева от поля ввода) через `bot.set_my_commands`.

- **Добавить команду** — впишите строку по аналогии. И **создайте обработчик** в `handlers/` (роутер с `@router.message(Command("имя"))`), иначе Telegram покажет команду, а бот не ответит.
- **Переименовать описание** — поменяйте текст справа.
- **Удалить** — сотрите строку (и обработчик, если он есть).
- **Порядок строк = порядок в меню.**

### Тексты-шаблоны (Меню 7, 8, 11, 12)

Некоторые сообщения содержат подставляемые значения (номер задачи, текст,
автор и т.д.). Они записаны как обычные строки с плейсхолдерами `{name}` —
хендлер подставляет значения через `.format(...)`. Не делайте их f-строками:
f-строка вычисляется при определении, а здесь нужен шаблон.

```python
MENU_8_SUCCESS = (
    "✅ <b>Задача #{task_id} добавлена!</b>\n\n"
    "📝 {text}\n\n"
    "👤 {user}\n"
    "📁 {category}\n"
    "🚦 {status}\n\n"
    "Посмотреть все задачи: /list"
)
```

Менять текст вокруг плейсхолдеров можно свободно; удалять/переименовывать
сами `{name}` — только если одновременно правите хендлер.

|-----------|------|-----------|
| Кнопки категорий | `menus.py` | `MENU_1_CATEGORIES` |
| Кнопки статусов | `menus.py` | `MENU_2_STATUSES` |
| Приветствие `/start` | `menus.py` | `MENU_3_INTRO`, `MENU_3_OUTRO` |
| Команды (меню Telegram) | `menus.py` | `MENU_4_COMMANDS` |
| Сообщения `/add` | `menus.py` | `MENU_5`…`MENU_9` |
| Тексты `/list` | `menus.py` | `MENU_10`, `MENU_11` |

> приветствия и списка команд — в `handlers/start.py`. Туда лезть не нужно,
> если только не меняете саму логику (а не тексты).
